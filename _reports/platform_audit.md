## 1. Access summary

- **URL**: https://app.aitextura.com/ → редирект на Keycloak `auth.aitextura.com/realms/aitextura/...`
- **Авторизация**: пройдена через email + пароль. Поддерживаются OAuth-провайдеры (Apple, Facebook, Google, Microsoft) и «Волшебная ссылка» (magic link) — отдельная ветка после ввода e-mail.
- **Двухступенчатая форма**: сначала e-mail → «Продолжить» → пароль → «Вход».
- **Язык**: переключён на RU через `Личный аккаунт → Меню профиля (внизу слева) → Language: RU`. Оригинальные русские лейблы зафиксированы.
- **Аккаунт**: пользователь принадлежит двум контекстам — `Личный аккаунт` (роль «личный», есть `История списаний`, баланс 62,18 $) и организация `AI TEXTURA` (роль `Участник`, баланс 125,30 $). Переключение через большую кнопку контекста в верху сайдбара.
- **Полномочия наблюдаемого аккаунта**: `Участник` в AI TEXTURA, плюс `Администрирование` (виден пункт `Панель поддержки` `/support-dashboard` со списком всех аккаунтов и кнопкой «Войти» — это супер-админ функция).
- **Скриншоты**: `00-login.png`, `00b-login-password.png`, `01-dashboard.png`, `02-notification-dialog.png` (post-login push-уведомления модал), `03-profile-menu.png` (меню профиля с RU/EN/Тема/Настройки/Что нового/Сбросить онбординг).

### 3.2 ИИ сотрудники (Агенты)
- **URL**: `/agents`, `/agents/:id`
- **Что есть в платформе (список)**:
  - Поиск по имени, кнопка `Нанять сотрудника`.
  - Информер «Самообучение: N записей ждут подтверждения. Откройте агента и подтвердите ответы — иначе чаты на паузе».
  - Таблица: Имя, Статус (Активен), Дата создания, Каналы, Таланты (число), Последняя активность, Чаты (`Live чат`), Действия (toggle статуса + меню).
- **Что есть в платформе (создание)** — модал `Новый сотрудник` с тремя путями:
  - **Вручную** — выбор готового шаблона из библиотеки: Personal Assistant, Learning Companion, Creative Helper, Health & Wellness, Task Management, Research Assistant, Other (пустой).
  - **Автоматически** — собирает по адресу сайта.
  - **Пустой агент** — без инструкций.
- **Что есть в платформе (редактирование агента)** — 12 вкладок:
  1. **Персона** — техническое имя / имя для представления / аватар; редактор промпта по разделам с кнопкой `Добавить раздел` и текст-блоками (плюс Raw XML toggle).

  3. **Самообучение N** — бейдж с числом записей.
  4. **Таланты** — каталог 30+ интеграций (см. 3.3).
  5. **Канал** — каналы/мессенджеры (см. 3.4).
  6. **Быстрые ответы** — шаблоны.
  7. **Профили** — настройка полей профиля клиента.
  8. **Рабочее время** — расписание.
  9. **Автодожим** — fallback-рассылки.
  10. **Уведомления** — триггеры (см. 3.7).
  11. **Версии** — история версий промпта/настроек.
  12. **Дополнительно** — язык ответа, голос (PRO ElevenLabs голоса: ash/coral/sage/onyx/alloy/echo/fable/nova/shimmer + скорость), команды агента (старт/стоп/очистка памяти/защита/обучение/отчёты), поведение (защита от взлома, стоп после ответа менеджера, пауза при бот-сообщениях, авто-старт после паузы, определение завершения диалога).

  - Внизу: «Предыдущий шаг»/«Следующий шаг» навигация по табам, плавающая панель «У вас есть несохранённые изменения / Отменить / Сохранить».

- «Возможно, инструкция неполная — агент не понял, что нужно вызвать инструмент.»
- **Использованные инструменты в этом кейсе**: список (`check_language` и т.д.).
- Кнопки: `← Назад`, `В инструкции`, `Инструкция ок →`.

**Шаг 3 из 4 — «Опишите проблему»**
- «Ваши ответы помогут отделу обучения ИИ улучшить агентов для похожих кейсов.»
- Превью: «Ответ агента: {текст}».
- Поле `Что должно было быть в ответе?` (textarea, плейсхолдер «Опишите правильный ответ или чего не хватило…»).
- Селект `В чём причина ошибки по вашему?`:
  - Неточность (выдуманы факты)
  - Неправильное понимание вопроса
  - Не использовал знания / tool
  - Грубость / неуместный тон
  - Слишком длинный / короткий
  - Другое
- Поле `Дополнительные комментарии` (textarea, плейсхолдер «Любая полезная информация для команды обучения…»).
- Кнопка `Далее →` disabled до заполнения первого textarea.

**Шаг 4 из 4 — «Спасибо! Ваша обратная связь важна»**
- «Эта информация уйдёт в отдел обучения ИИ. Мы используем её, чтобы агенты становились лучше. Обычно ответ приходит в течение 3 рабочих дней.»
- Сводка: `Ожидаемый ответ: {текст из шага 3}`, `Причина: {выбранная причина}`.
- **Ключевая фраза**: «Отчёт по контексту кейса будет автоматически приложен к заявке в поддержку.»
- Линк `📎 Открыть отчёт по контексту →` — даёт возможность посмотреть подробный отчёт о шагах решения агента до отправки.
- Кнопки `← Назад`, `Отправить`.

#### Что это означает
- «Палец вниз» в платформе **не просто сигнал** для аналитики — он **запускает SLA-обращение в поддержку**, в которое автоматически прикладывается отчёт о ходе работы агента (язык, инструменты, источники, финальное решение).
- Это **главный канал** для пользователя сказать «ИИ ответил неправильно» и получить помощь от отдела обучения, минуя ручное создание тикета.

## 7. Блокировки и ограничения сессии

- **Профиль клиента (chat detail panel)** — не удалось полностью раскрыть (пункт меню «Профиль клиента» не отреагировал на клик через JS). Зафиксирован только ярлык в меню действий чата. Скриншот `87-chat-menu-options.png` показывает текстовый список.
- **Создание реальной организации** — пропущено сознательно, чтобы не загрязнять аккаунт. Зафиксирована форма (`05-org-create-form.png`) и существующая организация `AI TEXTURA`.
- **Реальное создание тикета через палец вниз** — на шаге 4 нажата `Назад`, чтобы не отправлять реальную обратную связь. Скриншот шага 4 (`48-thumbdown-step4-support.png`) полностью показывает финальный экран с фразой «Эта информация уйдёт в отдел обучения ИИ» и линком «📎 Открыть отчёт по контексту →».
- **Приглашение участника в организацию** — кнопки/UI не видно у роли `Участник`. Есть алерт «Не удалось загрузить приглашения» на вкладке `Участники` — это намекает на наличие отдельного механизма (по-видимому, доступного только админам/владельцам). См. QUESTIONS.md.
- **Avito / WhatsApp прямой / Website widget** — в платформе таких **отдельных каналов нет** (хотя в текущей доке страницы есть). WhatsApp заходит через Wazzup. Для Task 3/4: либо удалить страницы, либо переписать как «WhatsApp через Wazzup» / «coming soon».
- **OAuth-flow для amoCRM/Kommo** — не запускался реально (кнопка `Подключить канал amoCRM` открывает popup OAuth-авторизации; пропущено).
- **Wazzup, Salebot, Umnico, SendAPI, HelpDeskEddy, Jivo каналы** — список платформ зафиксирован в `29-channel-platform-list.png`, но не открывались индивидуальные модалы для каждого (нет в фокусе миссии). Для Task 3/4 — их UI похож по структуре (имя, токен/ключ, настройки буфера/автоочистки).
- **Console errors** — встречались (`page-2026-05-07T*.log`), но критических блокировок не было. Скорее всего, телеметрия / sentry-нойз.
