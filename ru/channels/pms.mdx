## Что такое PMS-талант

PMS (Property Management System) — система управления номерным фондом отеля или объекта аренды. ИИ-сотруднику отеля **жизненно нужна** интеграция с PMS: без неё бот не сможет ответить на вопросы «Свободно ли на 5 ноября?» или «Сколько стоит люкс?», тем более не сможет создать бронирование.

В AI Textura PMS-системы подключаются через **таланты** — это MCP-серверы (Model Context Protocol), через которые ИИ выполняет операции в PMS прямо во время разговора.

<Tip>
  PMS — это не канал, а **талант**. Канал отвечает за разговор с гостем (Telegram, WhatsApp, бронированный мессенджер). Талант — за работу с номерным фондом. Чтобы отельный ИИ-сотрудник был полноценным, ему нужны оба: канал + хотя бы один PMS-талант.
</Tip>

---

## Поддерживаемые PMS-системы

В каталоге талантов доступны **6 PMS-систем**:

| PMS | Регион | Тип объектов | Тип авторизации |
| --- | --- | --- | --- |
| **MEWS** | Глобальный | Отели, сети отелей | Configuration ID + Connector Token |
| **Travelline** | РФ, РБ, мир | Отели, гостиницы | Hotel ID + Регион |
| **Bnovo** | РФ, СНГ | Малые отели, гостевые дома | Hotel ID + Login + Password |
| **RealtyCalendar** | РФ | Апартаменты, посуточная аренда | API-ключ |
| **Bronirui Online** | РФ | Гостевые дома, мини-отели | API-ключ |
| **MeHotel** | РФ | Отели, апартаменты | API-ключ |

<Note>
  Если вашей PMS нет в списке — напишите в [поддержку](/ru/guides/support). Мы регулярно расширяем каталог. Также можно подключить кастомный MCP-сервер через **«Создать талант»**.
</Note>

## Как подключить PMS-талант

<Steps>
  <Step title="Откройте «Таланты» агента">
    Перейдите в [ИИ-сотрудники](/ru/guides/ai-employees) → выберите сотрудника → вкладка **Таланты** → подвкладка **Обзор приложений**.
  </Step>
  <Step title="Найдите вашу PMS">
    В фильтре категорий выберите **Travel & Hospitality** (или используйте поиск по названию). PMS-таланты — `MEWS`, `Travelline`, `Bnovo`, `RealtyCalendar`, `Bronirui Online`, `MeHotel`.
  </Step>
  <Step title="Откройте модал подключения">
    Нажмите на нужную карточку — откроется модал с полями для авторизации.
  </Step>
  <Step title="Заполните данные авторизации">
    См. описание полей по конкретной PMS ниже. Часть данных нужно получить у вашего администратора PMS или на стороне поставщика.
  </Step>
  <Step title="Сохраните подключение">
    Нажмите **Подключить**. Талант появится во вкладке **Подключённые** на странице агента.
  </Step>
  <Step title="Проверьте на тестовом чате">
    Откройте встроенный тест-чат агента и задайте вопрос про доступность номеров на конкретные даты. ИИ должен сходить в PMS и вернуть ответ.
  </Step>
</Steps>

<Warning>
  Креды PMS — это доступ к коммерческим данным отеля (бронирования, тарифы, гости). Храните их безопасно. Не давайте логин/пароль третьим лицам и не публикуйте их.
</Warning>

## Параметры подключения по системам

### MEWS

<Frame>
  <img src="/public/screenshots/18-talent-mews.png" alt="Модал таланта MEWS" />
</Frame>

MEWS — облачная PMS для сетей и независимых отелей мирового уровня. Подключается через коннектор-токены MEWS.

| Поле | Описание | Где взять |
| --- | --- | --- |
| **Configuration ID** | Идентификатор конфигурации MEWS | В панели MEWS у администратора |
| **Client Name** | Имя клиента (отеля) | В настройках MEWS |
| **Hotel ID** | Идентификатор отеля в MEWS | В настройках MEWS |
| **Age Category Adult** | ID категории «Взрослый» | Категории гостей в MEWS |
| **Age Category Children** | ID категории «Ребёнок» | Категории гостей в MEWS |
| **Hotel Timezone** | Часовой пояс отеля | Настройки отеля |
| **Connector Client Token** | Токен клиента-коннектора | Запрашивается у MEWS |
| **Access Token** | Токен доступа | Запрашивается у MEWS |
| **Client** | Идентификатор клиентского приложения | Запрашивается у MEWS |
| **Enterprise ID** | ID предприятия (для сетей) | В настройках MEWS |

<Tip>
  Для сети отелей подключите по одному таланту MEWS на каждый отель — у каждого свой Configuration ID и Hotel ID. На разные отели сети заведите разных ИИ-сотрудников.
</Tip>

### Travelline

<Frame>
  <img src="/public/screenshots/19-talent-travelline.png" alt="Модал таланта Travelline" />
</Frame>

Travelline — российская/международная PMS, особенно популярна в СНГ.

| Поле | Описание | Значения |
| --- | --- | --- |
| **Hotel ID** | Идентификатор отеля в Travelline | Цифровой ID из кабинета Travelline |
| **Регион** | В каком регионе работает Travelline | `РФ` / `РБ` / `МИР` |

<Note>
  Регион определяет, к какому API-эндпоинту Travelline пойдут запросы. Если у вас гостиница в России — выбирайте `РФ`, в Беларуси — `РБ`, в остальных случаях — `МИР`.
</Note>

### Bnovo

<Frame>
  <img src="/public/screenshots/20-talent-bnovo.png" alt="Модал таланта Bnovo" />
</Frame>

Bnovo — облачная PMS для малых отелей и гостевых домов.

| Поле | Описание |
| --- | --- |
| **Hotel ID** | Идентификатор отеля в Bnovo |
| **Login** | Логин учётной записи Bnovo |
| **Password** | Пароль учётной записи Bnovo |

<Tip>
  Создайте в Bnovo отдельную «техническую» учётную запись для интеграции с AI Textura — будет проще управлять правами и при необходимости отозвать доступ.
</Tip>

### RealtyCalendar

PMS для апартаментов и посуточной аренды. Подключение по API-ключу из личного кабинета RealtyCalendar.

| Поле | Описание |
| --- | --- |
| **API Key** | Ключ API из настроек RealtyCalendar |

### Bronirui Online

PMS для гостевых домов и мини-отелей. Подключение по API-ключу.

| Поле | Описание |
| --- | --- |
| **API Key** | Ключ API из кабинета Bronirui Online |

### MeHotel

Российская PMS для отелей и апартаментов.

| Поле | Описание |
| --- | --- |
| **API Key** | Ключ API из кабинета MeHotel |

## Что ИИ умеет с PMS

После подключения PMS-таланта ИИ-сотрудник может:

- **Проверять доступность номеров** на конкретные даты.
- **Показывать тарифы** и описание категорий номеров.
- **Создавать черновик бронирования** или передавать данные менеджеру.
- **Отвечать на вопросы по конкретной брони** (если у клиента есть номер брони).
- **Проверять статус заезда / выезда** в течение дня.

<Tip>
  Объём операций зависит от возможностей конкретного PMS API и от того, какие права выданы интеграционной учётной записи.
</Tip>

## Настройка после подключения

1. **Опишите в [персоне](/ru/guides/persona) агента**, что ИИ — это администратор отеля. Укажите название отеля, тип номеров, политику бронирования и т. д.
2. **Подключите канал** — Telegram, WhatsApp через Wazzup или нужный мессенджер. См. [Каналы](/ru/channels).
3. **Добавьте [базу знаний](/ru/guides/knowledge-base)** с описанием услуг, политики отмены, правил отеля. PMS даёт цифры по номерам, база знаний — всё остальное.
4. **Протестируйте сценарии**: бронирование, изменение даты, вопрос про завтрак, запрос на отмену.

## Сеть отелей

Если у вас несколько отелей — на каждый отель заведите **отдельного ИИ-сотрудника** с **отдельным PMS-талантом** (свои Hotel ID / Configuration ID). Между сотрудниками клиента можно переключать через систему правил или маршрутизацию каналов.

<Tip>
  Для сети отелей удобно использовать единый канал-агрегатор и один номер WhatsApp, но **разных ИИ-сотрудников** под каждый отель — каждый со своим PMS, базой знаний и персоной.
</Tip>

## Частые вопросы

<AccordionGroup>
  <Accordion title="Что делать, если моей PMS нет в списке?">
    Напишите в [поддержку](/ru/guides/support) — каталог талантов регулярно расширяется. Альтернатива — подключить кастомный MCP-сервер через **«Создать талант»** (Тип сервера SSE / Streamable HTTP, авторизация по API Key или Bearer Token).
  </Accordion>

  <Accordion title="Можно ли подключить две разные PMS к одному агенту?">
    Технически — да, оба таланта появятся в списке подключённых. Но это редко имеет смысл: один отель = одна PMS. Скорее это применимо для разных объектов под одной учёткой агента, и тогда лучше развести их на отдельных ИИ-сотрудников.
  </Accordion>

  <Accordion title="ИИ говорит «не могу проверить доступность» — почему?">
    Проверьте: (1) талант PMS подключён и активен; (2) креды (Hotel ID, токены, логины) актуальны и не отозваны на стороне PMS; (3) у интеграционной учётки в PMS есть права на чтение календаря и тарифов; (4) в инструкции агента описано, что для вопросов по бронированию нужно использовать PMS-инструмент.
  </Accordion>

  <Accordion title="Можно ли разрешить ИИ создавать брони автоматически?">
    Да — если у PMS-таланта есть право на запись (создание брони) и в инструкции агента это явно разрешено. Для безопасности рекомендуем сначала отрабатывать сценарий «черновик брони + подтверждение менеджера», а полностью автоматическое создание включать только когда уверены в качестве диалогов.
  </Accordion>

  <Accordion title="PMS Travelline — что выбрать в поле «Регион»?">
    Если ваш отель в России — выберите `РФ`, в Беларуси — `РБ`, в любой другой стране — `МИР`. Это определяет, к какому API-эндпоинту Travelline пойдут запросы.
  </Accordion>

  <Accordion title="Креды MEWS у меня есть, но не знаю, какой именно «Configuration ID» нужен.">
    Configuration ID выдаётся отдельно для каждой интеграции в MEWS. Запросите у партнёр-менеджера MEWS «Configuration для интеграции с AI Textura» — они активируют коннектор и пришлют все нужные идентификаторы (Configuration ID, Client, Enterprise ID, Token-ы).
  </Accordion>

  <Accordion title="Безопасно ли хранить логин и пароль PMS в AI Textura?">
    Креды хранятся в зашифрованном виде и используются только для запросов к API PMS от имени интеграции. Тем не менее рекомендуем создать **отдельную учётную запись** для интеграции в вашей PMS (с минимально нужными правами) — так вы сможете в любой момент отозвать доступ, не затрагивая основных пользователей.
  </Accordion>
</AccordionGroup>
