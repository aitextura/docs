## Referral code and link

When an account is created, each user automatically gets a unique referral code and link. They never change.

| Element | What it is | Example |
|---|---|---|
| **Code** | A unique referral code tied to your account | `9C7MMZXY` |
| **Link** | A ready-made sign-up link with your code | `https://app.aitextura.com/sign-up?ref=9C7MMZXY` |

You can copy both fields in one click on the `/partner-program` page (the **Partner Program** item in the left menu).

<Tip>
  Sharing the link is more convenient -- it goes straight to the sign-up page with the code already filled in. The new user doesn't need to enter anything manually.
</Tip>

## How the referral system works

<Steps>
  <Step title="Share your link or code">
    Send the link to a colleague, post it on social media, add it to your email signature -- whatever works for you.
  </Step>
  <Step title="A new user signs up">
    They follow your link or enter the code during sign-up and create an AI Textura account.
  </Step>
  <Step title="The system records the connection">
    The platform automatically links the new user to your account as a referral.
  </Step>
  <Step title="You receive a reward">
    You get a bonus for every partner you invite. You can check the terms with the [Support](/en/guides/support) team.
  </Step>
</Steps>

## Partner counter

The **Partner Program** page (`/partner-program`) shows the **Total partners** block -- how many users signed up with your link or code. The counter updates automatically and counts only completed sign-ups.

<Note>
  If a user followed the link but didn't create an account, they aren't counted.
</Note>

## Two ways to invite

### Option 1: Referral link

Copy the link and send it any way you like. When someone follows it, the referral code is filled in automatically.

### Option 2: Referral code

Share the code verbally or in a message. The new user enters it manually during sign-up.

<Warning>
  With a code, the user may forget to enter it or make a typo. The link is more reliable.
</Warning>

## Where and how to share your link

The Partner Program works best when you reach the right audience. Proven approaches:

- **Recommend it to colleagues** -- a personal recommendation beats any advertising.
- **Professional chats and groups** -- Telegram chats about automation, business, and marketing.
- **Email signature** -- unobtrusive and works in the background.
- **A review or case study on your blog or social media** -- share how AI Textura helps your business.
- **Training materials** -- webinars, consultations, courses.

<Tip>
  Share your link honestly and explain that it's a referral program. Transparency builds trust.
</Tip>

## Important details

- The Partner Program is **active by default** for all users -- no extra setup is needed.
- **There's no limit on the number of invitees** -- invite as many users as you like.
- The program works **with no geographic restrictions**.
- Your code and link **don't change** -- they're tied to your account permanently.

## FAQ

<AccordionGroup>
  <Accordion title="Where do I find my referral code and link?">
    Open **Partner Program** in the left menu. The page shows the **Code** and **Link** fields -- you can copy both.
  </Accordion>
  <Accordion title="Can I change my referral code?">
    No, the code is generated automatically and tied to your account. It doesn't change.
  </Accordion>
  <Accordion title="What happens if someone follows the link but signs up later?">
    The referral code is passed through the link when it's followed. If the user closes the page and comes back later without the link, the connection may not be recorded. It's best to sign up right away.
  </Accordion>
  <Accordion title="A user signed up, but the counter didn't change -- what should I do?">
    Make sure the user followed your link or entered your code. If everything is correct but the counter hasn't updated, create a ticket in the [Support](/en/guides/support) section.
  </Accordion>
  <Accordion title="Do I need to set anything up for the program to work?">
    No. The Partner Program is active by default for all users.
  </Accordion>

  <Accordion title="How much is paid and when">
    A partner receives 20% of the invited customer's payments; payouts arrive between the 3rd and 7th of each month. There's no separate partner dashboard yet -- request a payout summary from [Support](/en/guides/support).
  </Accordion>
</AccordionGroup>
