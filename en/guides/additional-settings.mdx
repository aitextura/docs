## Reply language

A selector that defines which language the AI Employee uses to reply to customers.

| Value | Behavior |
|---|---|
| **In the user's language** (default) | The AI Employee automatically detects the customer's language and replies in it |
| **A specific language** (Русский, English, Қазақша, etc.) | The AI Employee always replies in the selected language, regardless of the customer's language |

<Warning>
  If you select a specific language, the AI Employee doesn't stop *understanding* messages in other languages. It understands everything -- but replies only in the selected language.
</Warning>

<Tip>
  Lock the language if all your customers speak the same language or if the AI Employee gets confused by auto-detection. Keep **In the user's language** for international business and tourism.
</Tip>

## Reply word limit

A number field that limits the length of the AI Employee's replies.

| Value | Behavior |
|---|---|
| **0** (default) | No limit -- the AI Employee decides the reply length itself |
| **Any number** (for example, 50 or 100) | The AI Employee tries to stay within the limit |

<Warning>
  This is a **soft limit**. The AI Employee doesn't cut a reply off mid-sentence -- it phrases it more concisely. It may occasionally go slightly over the limit.
</Warning>

<Tip>
  For Telegram/WhatsApp, 50–80 words works well. For complex consultations (legal, medical), use 0 or 150–200.
</Tip>

## Image recognition

<iframe className="w-full aspect-video rounded-xl" src="https://www.youtube.com/embed/noihUnchskY" title="Image recognition — how to set it up" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen></iframe>

A text field with instructions on what the AI Employee should pay attention to when analyzing photos, screenshots, and images from customers.

It's empty by default -- the AI Employee analyzes images in a general way. By filling it in, you focus the AI Employee on what matters for your business.

### Example instructions

| Business | Example instruction |
|---|---|
| Hotel | "Look for the booking number, check-in and check-out dates, number of guests, and the amount" |
| Online store | "Identify the product in the photo, its condition (new, used, damaged), and any defects" |
| Car service | "Describe the visible damage to the car, where it is, and roughly how severe it is" |
| Restaurant | "Identify the dish in the photo and its approximate ingredients" |

<Tip>
  The more specific the instruction, the more accurate the result. Instead of "analyze the photo", write: "Find the order number, date, and amount in the screenshot. If there's no number, ask the customer."
</Tip>

## Voice settings

A block of settings for voice replies. It lets the AI Employee reply with a voice message.

<Warning>
  Voice messages work only in [Telegram](/en/channels/telegram). For IP telephony, contact [Support](/en/guides/support).
</Warning>

### Standard mode vs PRO

| Mode | Description | When to use |
|---|---|---|
| **Standard** | Built-in platform voices. Connect instantly, no integrations needed | For basic voice-over, MVPs, testing |
| **PRO** | Voices from **ElevenLabs** (professional TTS quality). Requires an ElevenLabs API key in [/settings → Integrations](/en/guides/account-settings) | For premium scenarios, a branded sound, multilingual voice-over |

### PRO voices (ElevenLabs)

PRO mode gives you the signature ElevenLabs voices:

| Voice | Type |
|---|---|
| **ash** | male, neutral |
| **coral** | female, soft |
| **sage** | male, calm |
| **onyx** | male, deep |
| **alloy** | neutral, versatile |
| **echo** | male, expressive |
| **fable** | storytelling, narrative |
| **nova** | female, energetic |
| **shimmer** | female, warm |

Below the voice selector is the speech **speed control** (from x0.5 to x1.5).

### Connecting an ElevenLabs API key

The API key is set **globally for the account**, not per agent.

<Steps>
  <Step title="Get an API key from ElevenLabs">
    Sign up or sign in to [ElevenLabs](https://elevenlabs.io/) and copy the API key from your profile settings.
  </Step>
  <Step title="Open /settings → Integrations">
    On the AI TEXTURA platform: profile menu (bottom-left corner) → **Settings** → **Integrations** tab. For details, see the [Account Settings](/en/guides/account-settings) guide.
  </Step>
  <Step title="Paste the ElevenLabs key">
    Enter the key in the **ElevenLabs API key** field and save.
  </Step>
  <Step title="Turn on PRO in the agent">
    Go back to the editor of the agent you need → **Advanced** → **Voice** → switch the mode to **PRO**, then choose a voice and speed.
  </Step>
</Steps>

<Tip>
  For business communication (legal, medical, finance), the **sage** or **ash** voices at x1.0 work well. For youth-oriented projects, try **nova** or **shimmer** at x1.1–x1.2.
</Tip>

### Voice parameters

| Parameter | Type | Description |
|---|---|---|
| **Voice type** | Toggle | Standard / PRO (ElevenLabs) |
| **Voice** | Selector | In PRO: ash, coral, sage, onyx, alloy, echo, fable, nova, shimmer |
| **Speed** | Slider | x0.5 – x1.5 |
| **Style and emotion** | Text field | A style description: "calm and confident", "energetic and friendly" |
| **Reply to voice messages** | Selector | Voice + text / Voice only / Text only |

## <a id="komandy-agenta"></a>Agent commands

Service commands let you control the AI Employee **right from the chat** -- without opening the dashboard. This is handy for managers who work in the same chat as the AI Employee.

<Note>
  **Agent commands are global.** You set their text **once for the whole account** in [/settings → General](/en/guides/account-settings) (the General settings tab). On a specific agent's **Advanced** page, you see the same commands and can be sure they're current for all your agents at once.
</Note>

### Full list of commands

| Command | What it does | When to use |
|---|---|---|
| **Start AI** | Activates the AI Employee in the chat -- it starts replying again | The manager is done stepping in and hands the chat back to the AI |
| **Stop AI** | Pauses the AI Employee -- it stops replying but still "sees" messages | The manager wants to reply personally |
| **Clear memory** | Resets the current conversation's context -- the AI Employee "forgets" previous messages | The customer came with a new question, but the AI Employee clings to the old context |
| **Jailbreak protection** | Turns prompt injection protection on/off in this chat | Suspicious messages trying to "hack" the instructions |
| **Retrain** | Switches the AI Employee's reply to training mode -- adds an entry to [Self-Learning](/en/guides/self-learning) | The manager wants to train the agent on this case |
| **Report (all messages)** | Generates a conversation report -- all messages, including the archive | Handing a case over to another manager, audits |
| **Report (no archive)** | The same, but without archived messages | A short summary without noise |

### How commands work

A manager types a command in the chat -- the AI Employee recognizes it and performs the service action. The command **isn't sent to the customer** -- the system interprets it.

<Tip>
  Use unique, non-obvious commands (for example, `/aiti_pause` or `<<stop>>`) so a customer doesn't type them by accident. Common verbs like "stop" are risky.
</Tip>

<Steps>
  <Step title="Open /settings → General">
    Profile menu (bottom-left corner) → **Settings** → **General settings**.
  </Step>
  <Step title="Set the command text">
    For each command (Start AI, Stop AI, and so on), specify a trigger command.
  </Step>
  <Step title="Save and tell your managers">
    Make sure all managers know the current commands.
  </Step>
</Steps>

## Behavior toggles

A set of settings that control how the agent automatically interacts with managers and responds to unusual situations.

### Jailbreak protection

Blocks prompt injection attempts -- when a customer tries to make the agent "forget its instructions", "break character", or reveal a confidential prompt.

<Tip>
  Turn it on for agents that handle sensitive data or are publicly accessible (bot channel, widget). For internal demo agents, you can leave it off.
</Tip>

### Stop after manager reply

When on, the AI Employee pauses automatically as soon as a manager writes in the chat personally. This prevents the AI from "interrupting" a live specialist.

<Note>
  By default, it works together with **auto-start**: the AI turns off for 10–20 minutes, and if the customer sends a new message during that time, the AI resumes.
</Note>

### Pause on bot messages

When on, the AI Employee ignores messages from other bots in the same chat (for example, a CRM chatbot doesn't trigger the agent). This protects against "bot writes — bot replies — bot writes" loops.

### Auto-start after pause

The AI Employee automatically resumes work after a pause (10–20 minutes by default) -- if the customer wrote and the manager didn't respond.

<Tip>
  For 24/7 support, auto-start is useful -- customers won't be left without a reply at night. For premium sales, where a "human" style matters, it's better to control the AI Employee manually with commands.
</Tip>

### Conversation-end detection

The AI Employee analyzes the flow of the conversation and determines on its own when the conversation is over (the customer said goodbye, the issue is resolved). This affects how [Auto Follow-up](/en/guides/auto-followup) and [Notifications](/en/guides/notifications) work.

## FAQ

<AccordionGroup>
  <Accordion title="If I choose a specific language, will the AI Employee stop understanding other languages?">
    No. The AI Employee keeps understanding messages in any language -- but replies only in the selected one.
  </Accordion>

  <Accordion title="How are ElevenLabs PRO voices different from standard ones?">
    PRO sounds much more natural (lifelike pronunciation, emotion, pauses). This matters for premium businesses and audio content. The standard voices are good enough for typical replies and testing.
  </Accordion>

  <Accordion title="Where do I get an ElevenLabs API key?">
    Sign up at [elevenlabs.io](https://elevenlabs.io/), copy the key from your profile settings, and paste it into AI TEXTURA: [/settings → Integrations](/en/guides/account-settings). After that, PRO mode becomes available on all your agents.
  </Accordion>

  <Accordion title="Does voice work only in Telegram?">
    Yes, for now -- only Telegram. For IP telephony, contact [Support](/en/guides/support).
  </Accordion>

  <Accordion title="How does Jailbreak protection work?">
    The AI Employee recognizes prompt injections (attempts to make it break character, reveal its instructions, or ignore its restrictions) and neutralizes them. Turn it on for public agents and scenarios with sensitive data.
  </Accordion>

  <Accordion title="Where are agent commands stored?">
    Globally, at the account level: [/settings → General settings](/en/guides/account-settings). On a specific agent's Advanced tab, you see the same commands -- you can change them in only one place.
  </Accordion>

  <Accordion title="What happens if I send the Clear memory command?">
    The AI Employee resets the entire context of the current conversation -- as if the conversation just started. This is useful if the AI Employee is "stuck" in an old context.
  </Accordion>

  <Accordion title="A customer typed a command by accident -- what should I do?">
    Use unique, non-obvious commands (with unusual characters or prefixes). If it does happen, restart the AI Employee with the **Start AI** command.
  </Accordion>

  <Accordion title="What is Auto-start after pause?">
    After a pause (for example, after a manager reply), the AI Employee automatically resumes work after 10–20 minutes -- if the customer wrote and the manager didn't respond. This protects against "forgotten" chats.
  </Accordion>

  <Accordion title="Do I have to fill in every field in Advanced?">
    No. All settings have sensible defaults. Fill in only what you actually need.
  </Accordion>

  <Accordion title="How do I get the AI Employee to send photos, videos, or PDFs">
    The file must be stored in the cloud and open via a direct link without signing in -- ending in `.jpg`, `.pdf`, or `.mp4`. Then describe the condition in the [Persona](/en/guides/persona) or create a [Quick Answer](/en/guides/quick-answers): "If asked about the banquet menu, send the link …".
  </Accordion>

  <Accordion title="The customer gets a link instead of a photo">
    That's the channel's behavior, not the AI Employee's: Telegram expands media itself, while CRMs and some aggregators show only the link. Check that the link is direct and the file opens without signing in.
  </Accordion>

  <Accordion title="Can the AI Employee make and receive calls">
    Yes, voice calls are connected separately through your manager: a minute of conversation costs about $0.10–0.15 plus a monthly fee for the number. A Russian number isn't available yet -- the outgoing number will be registered in another country, and SIP routing adds connection delay.
  </Accordion>
</AccordionGroup>
